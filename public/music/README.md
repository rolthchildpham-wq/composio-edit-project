# Kho nhạc nền

Bỏ file .mp3/.m4a/.wav CÓ QUYỀN SỬ DỤNG vào đúng thư mục mood, rồi chạy: npm run scan-music

- soi-dong/      : tin công nghệ, giải trí, viral (upbeat 100-120 BPM)
- corporate/     : tin kinh doanh, tài chính (nhẹ, chuyên nghiệp)
- lofi-chill/    : hướng dẫn, kể chuyện thư giãn
- trang-nghiem/  : tưởng niệm, thời sự nghiêm túc (pad, piano chậm)
- quang-cao/     : video bán hàng (bắt tai, có nhịp)

Nguồn nhạc miễn phí/an toàn bản quyền:
- YouTube Audio Library (studio.youtube.com > Audio Library) — miễn phí, lọc theo mood
- Pixabay Music (pixabay.com/music) — CC0
- Mixkit (mixkit.co/free-stock-music) — miễn phí
- CapCut app > Audio (chỉ dùng khi đăng qua CapCut)
- Uppbeat.io — free có attribution

2 file *-generative.m4a là nhạc tự sinh bằng ffmpeg (vô hạn bản quyền) — dùng tạm khi chưa có nhạc thật.
